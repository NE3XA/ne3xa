About this panel

Nexa Dev stores content in localStorage on this device. It is ideal for drafting products, exams and notes before you wire a real backend.

From the public NE3XA site, press Ctrl + Alt + D to open this panel.

Export JSON regularly if you care about backups. Clearing browser data will wipe Nexa Dev content.
